# Morishita-engineer.github.io
## 🌟 プロジェクトの概要と目的

### 目的

「Webアプリをゼロから構築・デプロイする経験」の獲得と、座学で習得したJava/DB知識を実践で検証することを目的に、個人でメモアプリを制作しました。

### 主要機能

* メモの新規作成、一覧表示
* メモ内容の編集
* メモの削除
* ログイン、ログアウト

## 💡 技術的な挑戦と課題解決（試行錯誤）

このプロジェクトで特に困難だった課題と、それを乗り越えるために行った試行錯誤は以下の通りです。

### 1. サーバー（Servlet）とDB（MariaDB）の連携

* **課題:** 初めてのJDBC接続設定やデータベースからのデータの抽出において、接続エラーやデータ不整合が頻発しました。
* **試行錯誤:**接続設定、SQLクエリ、データの受け渡しロジック**の3点を一つずつ切り分けて検証。

### 2. AWS Linux環境へのデプロイ

* **課題:** ローカルと異なるLinux環境（AWS EC2）上でのTomcat設定、Java実行権限、及びデプロイ手順の確立が困難でした。
* **試行錯誤:** 公式ドキュメントや技術ブログを徹底的に調査し、環境変数の設定、Warファイルの配置、Tomcatの自動起動設定などを**独力で確立**。これにより、インフラ構築からアプリケーション提供までを一貫して行える能力を獲得しました。
